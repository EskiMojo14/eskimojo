Event listeners often belong together, including when it is time to remove
them. rad-event-listeners explores making that lifecycle easier to follow.

## One interaction, several events

A drag interaction might involve pointer movement, a release, and cancellation.
Thinking about those listeners as a group makes their shared purpose clearer.

```ts
import { radEventListeners } from "rad-event-listeners";

const unsubscribe = radEventListeners(document, {
  pointermove: (event) => {
    console.log("Pointer moved", event);
  },
  pointerup: (event) => {
    console.log("Pointer released", event);
  },
  pointercancel: (event) => {
    console.log("Pointer cancelled", event);
  },
});
// Later, when you want to remove the listeners
unsubscribe();
```

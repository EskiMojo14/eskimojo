Keycaplendar was my first project, and was how I learnt React. It's a calendar app for keycap group buys, inspired by the original [Google Sheet](https://docs.google.com/spreadsheets/d/139IWhxAuGHyLtapmzzbVygnP-sgnz0ihLjRQtX5dSKg/edit#gid=1446636608).

I made it using [Create React App](https://create-react-app.dev/) and [RMWC](https://rmwc.io/), a React wrapper for Material Design components.

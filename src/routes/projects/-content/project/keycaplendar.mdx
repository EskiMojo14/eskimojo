Keycaplendar was my first project, and was how I learnt React. It's a calendar app for keycap group buys, inspired by the original <a href="https://docs.google.com/spreadsheets/d/139IWhxAuGHyLtapmzzbVygnP-sgnz0ihLjRQtX5dSKg/edit#gid=1446636608" target="_blank" rel="noopener noreferrer">Google Sheet</a>.

I made it using <a href="https://create-react-app.dev/" target="_blank" rel="noopener noreferrer">Create React App</a> and <a href="https://rmwc.io/" target="_blank" rel="noopener noreferrer">RMWC</a>, a React wrapper for Material Design components.

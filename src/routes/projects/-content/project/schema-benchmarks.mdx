Created in collaboration with [Open Circle](https://github.com/open-circle) (an open source organisation led by [Fabian Hiller](https://github.com/fabianhiller)), Schema Benchmarks aims to provide detailed and transparent comparisons of schema validation libraries.

It measures many aspects of schema performance, including download size, parsing speed, and validation efficiency, providing developers with a clear understanding of the trade-offs between different schema validation libraries.

I built it using [Tanstack Start](https://tanstack.com/start) and [React](https://react.dev). Visually, it's inspired by my <Link to="/projects/$slug" params={{ slug: "neocities" }}>Neocities</Link> page, which is inspired by IDE design aesthetics.

Inspired by [`redux-undo`](https://github.com/omnidan/redux-undo) and [`createEntityAdapter`](https://redux-toolkit.js.org/api/createEntityAdapter), this package provides utilities for managing undoable state. It can be used with Redux, or any other state management solution (such as Zustand).

```ts
import { createHistoryAdapter } from "history-adapter";

interface CounterState {
  value: number;
}

const counterAdapter = createHistoryAdapter<CounterState>({ limit: 5 });

const initialState = counterAdapter.getInitialState({ value: 0 });

const incrementBy = counterAdapter.undoable((state, by = 1) => {
  state.value += by;
});

const newState = incrementBy(initialState, 2);

const previousState = counterAdapter.undo(newState);
```

`mix-n-matchers` contains a set of matchers I created to use with Jest (or any compatible testing framework) to make assertions more semantic. It also includes some utility functions.

```ts
import { every } from "mix-n-matchers/utilities";

const responses = await Promise.all(ids.map((id) => fetchData(id)));

await every(responses, async (response) => {
  expect(response).toBeOk();
  await expect(response).toHaveJSONBody({
    id: expect.typeOf("string"),
    name: expect.typeOf("string"),
  });
});
```

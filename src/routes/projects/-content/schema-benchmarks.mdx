Runtime validation libraries turn unknown data into something an application
can work with confidently. Comparing them is more interesting than picking
the tallest bar on a chart.

## Numbers need context

Different inputs, validation rules, and error-reporting requirements can tell
different stories. A useful comparison should make those assumptions visible.

This draft page leaves room for a deeper explanation of the benchmark setup,
how results are presented, and the limitations readers should keep in mind.

## Beyond the benchmark

The website is also a place to explain the results. This project page uses the
same broad content approach: small, validated metadata for discovery, with a
separate MDX document for the full story.

I also contribute to Valibot, a schema validation library for checking data at
runtime while keeping TypeScript types in sync.

## Contributing to validation tools

Validation sits at the boundary between the data an application receives and
the assumptions its code can safely make.

This draft leaves room for specific examples of my contributions and the
decisions behind them. Valibot is a collaborative project, not a library I
authored independently.

## Used on this site

This site uses Valibot to validate project frontmatter, among other inputs.
The documentation and repository above are the best starting points for
exploring the library itself.

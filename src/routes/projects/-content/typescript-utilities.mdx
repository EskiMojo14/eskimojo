Not every project needs to be a whole application. Sometimes the useful thing
is a small library with one clear job.

## history-adapter

Undo and redo introduce a little time travel into application state. This is
space for an example of how the history utilities fit into a real interaction.

## rad-event-listeners

Event listeners often belong together, including when it is time to remove
them. This section can show how grouped listener management makes that
lifecycle easier to follow.

## mix-n-matchers

Tests should say what they mean. Custom Jest-compatible matchers can make
assertions read more like the behavior they protect.
